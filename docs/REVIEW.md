# コードレビューと修正提案（2026-10）

対象：Green 関数の計算（`legacy/paper-2010/GrnEP_pro/`）、表の読み込みと補間（`standalone/common/readgrnep.f`、2010 年版の行列要素ファイル内の同等コード）、生成器での使い方（`GRNMOD`、`GGTT`/`GGTTRES`、`CORR`）、スタンドアロン版の入出力。
**このドキュメントは提案である。** 修正は承認されたものから別イシュー・別 PR で行う（イシュー #17）。

環境：`docker/Dockerfile`（Ubuntu 24.04 / gfortran 13 / LHAPDF 6.5.5）。
各項目の確度：**verified**＝コンテナで実行して確かめた／**read**＝コードを読んで確認したが実行していない／**inference**＝推論。

用語：「2010 年版」＝MadEvent 4.4.42 のプロセスディレクトリ（`legacy/paper-2010/`）、「スタンドアロン版」＝BASES/SPRING 版（`standalone/`）。Γ は Green 関数による補正因子 $G/G_0$（[green-function-tables.md](green-function-tables.md)）。

## このレビューで行った検査

| 検査 | 内容 | 道具 |
|---|---|---|
| 自由場テスト | $\alpha_s=0$ で表を作ると厳密に Γ = 1 になるはず。ずれが Schrödinger 方程式の解法と Fourier 変換の数値誤差 | `GrnEP_pro` を $\alpha_s=0$ で部分実行、`scripts/check/compare_tables.py free` |
| 再現テスト | 同梱の表と同じ $\alpha_s=0.1534$ で一部のエネルギー点を計算し直し、同梱の表と比べる | `scripts/check/compare_tables.py diff` |
| 格子の索引 | 高エネルギー側の表で、運動量 → 区間番号（`PINT`）が格子点（`PP`）と整合するか | `scripts/check/pint_check.f` |
| 範囲外の値 | 表の範囲外で返る Γ | `scripts/check/grn_extrap.f`（#9） |
| 回帰テスト | スタンドアロン版 4 終状態の σ と LHE、Green 関数の表 4 枚（一部のエネルギー点）のチェックサムを、変更の前後で比べる（#29） | `scripts/check/regression.sh` |

部分実行は、`GrnEPthre.f` のエネルギーを 100 点おき、`GrnEPhigh.f` を 50 点おきにして行った（[green-function-tables.md](green-function-tables.md) の手順で `DO 50 IE` の刻みだけ変更）。

## 優先度：高

### P1. スタンドアロン版は表より高いエネルギー（$E>830$ GeV）で Γ を線形外挿する — verified（値）
- `standalone/common/readgrnep.f` の `HOKAN2D` は、$E > E_{\max}=830$ GeV（$\sqrt{\hat s}\gtrsim 833$ GeV）で最後の区間を延ばして**線形外挿**する。2010 年版は同じ場所で Γ = 1（補正なし）を返す。
- 外挿値は物理的でない（Γ は高エネルギーで 1 に近づくはず）。1 重項で $E$ = 2000 GeV（$\sqrt{\hat s}\approx 1.23$ TeV）のとき Γ = 0.62 − 0.25i、つまり $|\Gamma|^2\approx 0.44$。8 重項で 0.82 + 0.46i。
  | $E$ [GeV] | 830 | 1000 | 2000 |
  |---|---|---|---|
  | 1 重項, p = 0 | 0.971 + 0.044i | 0.920 + 0.002i | 0.618 − 0.246i |
  | 8 重項, p = 0 | 1.002 − 0.008i | 0.975 + 0.059i | 0.818 + 0.455i |
- 影響（inference）：$m_{t\bar t}\gtrsim 0.9$ TeV の裾で、スタンドアロン版の断面積が補正なしより系統的に小さくなる。表の範囲外（$m_{t\bar t}>833$ GeV）の事象は、14 TeV の `blvblv`（スタンドアロン版、20000 事象）で 6.1%、$m_{t\bar t}>900$ GeV は 4.4%（verified）。
- **提案**：表の範囲外では 2010 年版と同じく Γ = 1 を返す（あるいは $E_{\max}$ の値で止める）。高い $m_{t\bar t}$ を扱うなら表を高エネルギーへ延ばす。

### P2. スタンドアロン版の LHE で、qq̄ 始状態のフレーバーが常に d — verified
- 断面積は u, d, s, c の和で正しく計算している（`PTFL`）が、`lheout*.f` は始状態を常に `IDUP = ±1`（d, d̄）と書く。クォークがどちらのビームから来るか（qq̄ / q̄q）だけは区別する。
- LHE で確認：qq̄ 由来の事象はすべて (1, −1) か (−1, 1)。2010 年版（MadEvent）は u, d, s, c をパートン光度に従って書く。
- 影響（inference）：シャワーの始状態放射（後ろ向き発展）や PDF の再重み付けが、qq̄ 事象（14 TeV で全体の約 13%）で誤ったフレーバーを使う。
- **提案**：SPRING で事象を作ったあと、その点のパートン光度の比 $f_q(x_1)f_{\bar q}(x_2)$ に従ってフレーバーを確率的に選び、`IDUP` に書く。

### P3. 表のパラメータと生成器のパラメータが食い違っても止まらない — read
- 表の 1 行目には $m_t$, $\Gamma_t$, $\alpha_s(\mu_B)$ がある。2010 年版は `TMASS` と比べて unit 9 に "Parameters inconsistent" と書くだけで続行する（$\Gamma_t$, $\alpha_s$ は比較相手が未設定）。スタンドアロン版は比較しない。
- `param_card*.dat` で $m_t$ を変えて表を作り直し忘れると、黙って別パラメータの補正を掛ける。
- **提案**：$m_t$, $\Gamma_t$ が表と違えば停止する（許容差つき）。

## 優先度：中

### P4. K 因子が LHC 14 TeV に固定 — read
- `DATA KF/1.14D0,1.39D0,1.16D0/`（スタンドアロン版の `EG_*.f`、bwbw は `kfac.inc`、2010 年版は `GrnFnc_*/kfac.inc`）。7 TeV、Tevatron の値はコメントアウトで並んでいる（論文 Table 1）。
- スタンドアロン版は `topbs.nml` で `RS` を変えられるが、K 因子は変わらない。`bwbw` の既定は `RS = 7 TeV` なのに K 因子は 14 TeV の値。
- **提案**：`RS` に応じて K 因子を選ぶ（14 / 7 TeV / Tevatron）か、`topbs.nml` で `KF` を指定できるようにする。

### P5. 閾値側の表で、$E>0$ かつ小さい $p$ の数値誤差が大きい — verified（誤差）／inference（原因）
- 自由場テスト（Γ = 1 が正解）：$|\Gamma-1|$ は高エネルギー側の表の全域と、閾値側の $E<0$ で $\lesssim 2\times10^{-3}$。閾値側の $E\ge0$ では **$p=0$ の列だけ**大きい。
  | $E$ [GeV] | 0 | 10 | 20 | 30 |
  |---|---|---|---|---|
  | $p=0$ | 0.007 | 0.048 | 0.053 | 0.088 |
  | $p\ge 20$ GeV（最大） | 0.001 | < 0.001 | < 0.001 | < 0.001 |
- 再現テストでも、$E\ge0$ の差は $p=0$ で最大 0.11、$p=1$ GeV で 2〜3% と小さい $p$ に集中し、on-shell 運動量 $p_0=\sqrt{m_tE}$ の ±10 GeV では $<10^{-3}$。
- 原因（inference）：赤外側の打ち切り半径 `RIR` を「$|u(r)|<10^{-4}$」で決めているが、$p\to0$ では被積分関数が $m\,r\,u(r)$ と $r$ に比例して重くなる。$E$ = 30 GeV では `RIR` ≈ 4.8 GeV⁻¹ で、打ち切った裾が数 % 残る。
- 影響（inference）：トップの運動量（$t\bar t$ 静止系）が数 GeV 未満の事象だけ。$E>0$ では位相空間（$p^2dp$）が小さい。
- **提案**：`RIR` の判定に重み（$p\to0$ では $r|u|$）を入れる、または $p$ が小さい列は解析的な裾の補正を足す。

### P6. 表が厳密には再現できない — verified（差）／read（原因）
- 同じパラメータで計算し直すと、on-shell 付近では $10^{-3}$ 以内、高エネルギー側も $2.5\times10^{-3}$ 以内で一致するが、P5 の小さい $p$ では数 % 違う。
- 原因（read）：(a) 収束しないとき刻み数 `NLOOPT` を増やすが、これは `DATA` で初期化した変数で、**次のエネルギー点以降にも持ち越される**。計算するエネルギー点の順序や間引き方で結果が変わる。(b) 収束判定の比較相手（`A1P`, `A2P`, `A7P`, `A8P`, `D0`）が初回は未初期化。
- **提案**：各エネルギー点の初めに `NLOOPT` と比較用の変数を初期化する。

### P7. 高エネルギー側の表で、on-shell 運動量のすぐ上の区間を取り違える — verified（索引）／inference（影響）
- `PINT` は、$p$ が $(p_0,\ p_0 + A\,RR^M)$（区間 $[PP(M), PP(M+1)]$ の下側約 45%）にあるとき、1 つ手前の区間 $M-1$ を返す。その範囲は補間ではなく外挿になる。$E$ = 40, 200, 800 GeV のどれでも、909 点中 4 点（すべてこの範囲）で起きる。
- 原因（read）：`PP` は $p_0$ より上の点を $p_0 + A\,RR^M(1-R_1^{k})/(1-R_1)$（$k = IP-M+1$）で置くので、`PP(M)` の続きとして $k=1$ が `IP = M` になるが、`PINT` の逆算が $k\in(0,1)$ を `IP = M-1` に落とす。
- 影響（inference）：外挿の距離は格子間隔（0.1〜0.4 GeV）の半分以下で、高エネルギーでは Γ が滑らかなので小さい。
- **提案**：`PINT` の $p>p_0$ の分岐を `PP` と整合させる（$k$ の切り捨ての基準を直す）。

### P8. ITR=1 で 2010 年版が約 3% 高い — 参照
- #9 で 2 つのバグを直したあとも残る差。行列要素は点ごとに一致し、積分器に依存しない推定はスタンドアロン版を支持している。→ #11、[versions-2010-2015.md](versions-2010-2015.md)。

## 優先度：低

### P9. `FOURIER` の $p=0$ で UV 側の項に余計な $p$ が掛かる — read（バグ）／verified（影響が無視できること）
- `IF (P.EQ.0D0) SIGUV = P*MU*RUV**2/2D0` は常に 0。正しくは `MU*RUV**2/2D0`（$\int_0^{R_{UV}} m\,r\,dr$）。
- `RUV` は $10^{-6}$ GeV⁻¹ 程度（`fort.13`）なので、欠ける量は $\sim10^{-10}$ で無視できる。P5 の $p=0$ の誤差の原因ではない。
- **提案**：P5 を直すときに合わせて直す。

### P10. 表より低いエネルギー（$E<-50$ GeV）の扱いが版で違う — verified（値）
- 2010 年版は Γ = 1、スタンドアロン版は最初の区間から外挿する（1 重項で $E=-100$ GeV のとき 1.08〜1.13）。両方のトップが大きく off-shell の領域で、寄与は小さい（inference）。
- **提案**：P1 と同じ方針でそろえる。

### P11. 同梱の表の $\alpha_s(\mu_B)$ はコードの計算値と違う — verified
- 同梱の表のヘッダは 0.1534、`GrnEP_pro` が QCD-PEGASUS で計算する値は 0.15329。同梱の表はコメントアウト中の `ASB = 0.1534D0` で作ったとみられる。再現テストは 0.1534 を直接与えて行った。
- **提案**：どちらを標準にするか決め、コードの既定を同梱の表に合わせる。

### P12. 2LRGI ポテンシャルはそのままでは動かない — verified
- `Vqcd_2LRGI.f` を選ぶと実行時にセグメンテーション違反で落ちる。初期化 `CALL SETVPR(...)` が主プログラムでコメントアウトされている。
- **提案**：2LRGI のときだけ `SETVPR` を呼ぶ。

### P13. 収束しないときの再試行に上限がない — read
- `SOLVE` は、$r\to0$ で収束しなければ `X1 = X1 - 1` で、$r\to\infty$ で収束しなければ `X1 = X1 + 0.2` と `NLOOPT + 5000` で、上限なく再試行する。
- **提案**：回数に上限を設け、超えたらその点を警告して止める。

### P14. 格子の定数が 3 か所にある — read
- 書く側（`GrnEP_pro/tblgrnep.inc`）、スタンドアロン版の読む側（`standalone/common/tblgrnep.inc`）、2010 年版（行列要素ファイルの `SETUPGRN` に直書き）。読む側は格子の点数と `RR` は表のヘッダと照合するが、範囲（$E_{\min}$ など）は照合しない。
- **提案**：読む側は格子の範囲も表のヘッダから取る。

### P15. `bjjbjj` の既定 `IBSS=2` は初回に動かない — read
- `IBSS=2` は前回の BASES の格子（`fort.55`）を読む設定。`scripts/run_standalone.sh` は `IBSS=1` を与えるので問題にならないが、プログラム単体では初回に失敗する。
- **提案**：既定を `IBSS=1` にする。

### P16. スタンドアロン版の LHE の細部 — verified
- b の質量欄が 0（運動量は $m_b$ = 5 GeV で計算）、重みが 1、banner なし、プロセス番号が 1 つだけ。シャワープログラムによっては質量欄から運動量を作り直すので、b の質量の扱いがずれうる（inference）。
- **提案**：質量欄に $m_b$ を書く。重みは σ/N、banner に生成条件（`topbs.nml`、表のパラメータ）を書く。

### P17. `GrnEP_pro/Makefile` が `g77` 前提 — verified
- `make LD=gfortran FFLAGS="-O3 -ffixed-line-length-132 -std=legacy -w"` で 3 種のポテンシャルとも作れる。
- **提案**：既定を gfortran にする。

## 追加の指摘（2026-10、コメント追加と gfortran の警告の整理で見つけたもの、#29）

自作のファイルに英語のコメントを足す作業（#29）で、コードを読んで見つけた点。確度は各項目に書く。

### P18. LHE で、W のハドロン崩壊のクォークの種類が電荷と合わない — read（コードで確認）
- `blvbjj/lheout_12.f` は W⁻ の崩壊先を u と d̄（`IDUP = 2, -1`、電荷の和 +1）と書く。正しくは d と ū。
- `bjjbjj/lheout.f` は W⁺ 側を ū と d（電荷の和 −1）、W⁻ 側を u と d̄（+1）と書き、両方とも逆。行列要素（`me_*E.f`）のラベルとも合わない。
- 影響（inference）：シャワープログラムの電荷保存の検査で、警告や事象の棄却が起こりうる。
- **提案**：W⁺ → u d̄、W⁻ → d ū に直す（`IDUP` の符号を入れ替える）。P2 と合わせて直すとよい。

### P19. 反クォークが第 1 ビームから来る始状態（q̄q、`IPART=-1`）に K 因子が掛からない — read（コードで確認）
- `sigh_*E.f` の K 因子の分岐は `IPART=1`（qq̄、クォークが第 1 ビームから来る）と `IPART=2`（gg）だけで、`IPART=-1`（q̄q、反クォークが第 1 ビームから来る）がない。`IKF=1` でも qq̄ チャンネルの半分は NLO の規格化（`KF(3)=1.16`）なしになる。2010 年版は qq̄ と q̄q の両方に掛ける。
- 影響（inference）：14 TeV で qq̄ は全体の約 13% なので、全断面積で約 1%。
- **提案**：`IPART.EQ.1 .OR. IPART.EQ.-1` にする。

### P20. `bjjbjj` の LHE で、サブプロセスの番号を取り違えることがある — read
- `sigh_bjjbjjE.f` は `COMMON/PROC/` にサブプロセスの「位置」（`IPROC`）を入れるが、`bjjbjj/lheout.f` はそれを「番号」（`OPROC(IPROC)`）として読む。両者が一致するのは、有効なサブプロセスが番号順に先頭から並ぶとき（`IPART=0, ICLR=0` と `IPART=1`）だけ。たとえば `IPART=2`（gg だけ）では、gg の事象が LHE に q q̄ の始状態で書かれる。
- **提案**：他の終状態と同じく `OPROC(IPROC)` を入れる。

### P21. `GrnEPhigh.f` の再試行で、増やす刻み数の変数が違う — read
- 高エネルギー側のプログラムのループは `NLOOPH` を使うが、$r\to\infty$ で収束しないときの再試行は `NLOOPT` を増やす（閾値側と同じ書き方のまま）。再試行しても刻み数は増えず、積分範囲が 0.2 広がる（刻みが粗くなる）だけ。
- `I8` の初期値が閾値側（1）と違って 0 なので、収束の数え始めが 1 歩遅れる（害はない）。
- **提案**：`NLOOPH` を増やす。P6・P13 と合わせて直す。

### P22. VEGAS（`IBSS=0`）の経路はそのままでは使えない — read
- `intvegas.f` は 10 変数までの配列だが、EG は 12（bwbw）または 18 変数で呼ぶ。また `IBSS=0` の分岐は結果を `SIG` に入れない。
- **提案**：使わない経路として docs に明記するか、配列の大きさと結果の受け渡しを直す。

### P23. `main_*`／`tot_*` はそのままでは Docker で動かない可能性がある — read
- `main_blvblv`, `main_bwblv`, `tot_bwblv` は `SETPDF` 経由で `cteq6l.LHpdf`（CTEQ6L、NLO の α_s）を読むが、Docker イメージは `cteq6l1` しか入れていない。
- `main_*` は param_card の Γ_t を LO の値（`RGAMT`）で上書きする。Green 関数の表（Γ_t = 1.4911 GeV）とずれうる（P3）。
- `main_bwblv` は $m_{t\bar t}$ の走査ループがコメントアウトされていて、344 GeV の 1 点だけを計算する。
- **提案**：使うなら PDF セットを Docker に足し、Γ_t の扱いを表とそろえる。

### P24. その他の小さな点 — read
- `EG_blvbjj` と `tot_bwblv` は、作っていないヒストグラム（33, 34, 36）を `XHSAVE2` で書こうとする（BASES が警告を出して飛ばす）。
- `blvblv`, `blvbjj`, `bjjbjj` の `KINECUT` は中身がすべてコメントアウトで、`ICUT=1` が効かない。`bwblv` の `KINECUT` は ΔR²（パートン系）で b̄ と μ⁻ が近い事象だけを残す。
- `PI = 3.1415923D0`（桁の誤り）が `sigh_*` の一部にある。`IDYN=1` のときの g_s にだけ入る。
- `EG_bwbw` の `MKHIST` は `X(10)` と宣言して 12 個を回す（呼び出し側の配列が 12 個なので動いている）。
- `tot_bwblv` の動的スケール（`IDYN=1`）は、使われないローカルの COMMON に結合定数を書くので、PDF のスケールしか変わらない。
- `helcomb.f` は最後に `DEG(0)`（宣言の範囲外）に書く。`GRNMOD` の `LAM` は `DSQRT` の後で `MAX(0,·)` を取るので、負の引数を防げない。
- `common/ptfl.f` は qq̄ に b も足すが、`sigh_*E.f` 内の `PTFL` は d, u, s, c だけ（EG が使うのは後者）。
- 古い `sigh_bwblv.f`, `sigh_blvblv.f` は、トップの不変質量が m_b + m_W より下まで動くので、`ITR=1` にすると `CORR` で 0 割りになる（既定は `ITR=0`）。

## gfortran の警告（リンター、2026-10、#29）

`gfortran -std=legacy -Wall -Wextra -fsyntax-only` を、自作のファイル（`standalone/*/{EG,main,tot,sigh}_*.f`、`standalone/common/` の自作ルーチン、`GrnEP_pro/GrnEP{thre,high}.f`）に掛けた。

- **直したもの**：対象のファイル自身で宣言していて使っていない変数・PARAMETER（138 件）。修正前後で、スタンドアロン版 4 終状態の σ と LHE、Green 関数の表 4 枚がビット一致した（`scripts/check/regression.sh`、verified）。
- **残したもの**：

## 範囲外（文書化のみ）

- **エネルギーの定義**：`GRNMOD` は $E=\hat s/(4m_t)-m_t$（$=p_{\rm on}^2/m_t$）を使い、$\sqrt{\hat s}-2m_t$ は使わない（コメントアウトで残っている）。閾値付近では同じで、高エネルギーでは違う。設計上の選択。
- **高エネルギー側の表の $E$ 方向の補間**：$p$ の格子は各 $E$ の $p_0=\sqrt{m_tE}$ に追従する。補間は同じ格子番号どうしで行うので、$p/p_0$ についての補間になる。on-shell 付近の構造が $p_0$ と一緒に動くので、妥当な選択。
- **ITR=1 の `CORR`**：2010 年版はトップの不変質量が $m_W+m_b$ 以下で 0 を返す。スタンドアロン版はその領域を位相空間から外す（`MWCUT1`）。どちらも $m_W$ は on-shell の値で幅を計算する。
- **修正済み**（#9）：2010 年版 `blvblv` の ū u サブプロセス欠落、ITR=1 INR=0 でのヘリシティ選択によるジョブ消失。[versions-2010-2015.md](versions-2010-2015.md) の「Fixes to the 2010 code」。
